# Розовая роза

Статический сайт: роза из символов, осыпание лепестков при нажатии и нежная надпись после десяти нажатий.

## GitHub Pages

Загрузите содержимое этой папки в корень репозитория. В Settings → Pages выберите Deploy from a branch, ветку main и /(root), затем Save.

index.html должен лежать в корне, а папка fonts — рядом с ним. Сборка и Node.js не нужны.

Comfortaa распространяется по SIL Open Font License; лицензия лежит в fonts/OFL.txt.
